NVDA container navigation reproduction

In Chrome with NVDA in browse mode, press Control+Home, then 2 to reach the first example heading. Press L to enter its outer list, then comma to move past that list. The expected destination is the button immediately after the outer list, not its last nested item.

For the UI Automation case, set “Use UI Automation to access Microsoft Edge and other Chromium based browsers” to “Yes” in NVDA’s Advanced settings and restart Chrome. Repeat with “No” as a comparison. No Internet connection, extension or script is required by this page.
